これまでの 2 つの演習では、ユーザーエクスペリエンスを改善し、機能を追加する 3 つのタスクを Copilot cloud agent に依頼しました。cloud agent は非同期かつ自律的に作業しますが、タスクを監視することも重要です。

cloud agent に割り当てたタスクは、GitHub.com の[エージェントページ][agents-page]など、さまざまなツールで管理できます。このミッションコントロールでは、オープンなプルリクエスト (PR) があるエージェントタスクをすべて確認できます。実行された操作を調べたり、進行中のセッションに追加の指示を送ったりできます。

このレッスンでは、次のことを行います。

- cloud agent のタスクを監視するために、エージェントページを確認します。
- 進行中のセッションに追加の機能を依頼し、作業の方向を調整します。

## シナリオ

チームは、エージェントにハイコントラストモードの作成を依頼した後、ライトモードも追加したいと考えました。サイトのスタイルと切り替え機能を更新しているところなので、ライトモードも同時に追加するのが合理的です。エージェントの作業を調整し、ハイコントラストモードに加えてライトモードも実装させます。

## Copilot cloud agent のタスクを確認する

Copilot cloud agent に割り当てたタスクの現在の状態を確認します。

1. [Copilot のエージェントページ](https://github.com/copilot/agents)に移動します。
2. メインペインと左ペインの両方にタスクの一覧が表示されます。Copilot に割り当てた次のタスクが含まれていることを確認します。
    - コードベースのドキュメントを更新する。
    - ゲームを変更する API を生成する。
    - Web サイトにハイコントラストモードを追加する。
3. 実行中のタスクを選択し、Copilot が実行した操作を確認します。次のような操作が含まれる場合があります。
    - リポジトリからコードをチェックアウトする。
    - Copilot の作業環境を作成する。
    - Model Context Protocol (MCP) サーバーをセットアップする。
    - 割り当てられたタスクを完了するための各種手順を実行する。

> [!NOTE]
> 表示される手順は、Copilot の作業状況や実行方法によって異なります。

4. 右側に表示されるプルリクエスト (PR) ペインも確認します。ここでは、PR と変更されたファイルを確認できます。

## cloud agent の作業を調整する

実行中のタスクを確認したので、エージェントがハイコントラストモードを作成している間にライトモードの切り替えも追加するよう依頼します。

1. ハイコントラストモードを追加するセッションを選択します。エージェントが使うタイトルや作業状態によって、表示される名前は異なります。

    ![ミッションコントロールのアクセシビリティセッション](../../../_images/ex6-accessibility-session.png)

2. セットアップが完了し、作業が始まったことを示すメッセージが表示されるまで数分待ちます。
3. **Steer active session while Copilot is working** ダイアログに次のプロンプトを入力します。

    ```plaintext
    ハイコントラストモードを作成しているので、ライトモードも追加してください。ユーザーが表示モードを選択できるように、ライトモード用のスイッチも必要です。
    ```

    ![Copilot の作業中にアクティブなセッションの方向を調整するダイアログが強調表示された、エージェントページのタスク画面](../../../_images/ex6-steer-cloud-agent-task.png)

4. <kbd>Enter</kbd> を押してプロンプトを送信します。
5. Copilot がプロンプトを認識し、作業に取り入れたことを確認します。

## Copilot の作業を待つ

これまでと同じように、Copilot は更新されたタスクに取り組みます。プロンプトを送信した時点で実行していた手順が終わると、新しい依頼をワークフローに取り込みます。

作業には数分かかります。その間に、これまでに学んだことを振り返ってください。

## まとめと次のステップ

Copilot のエージェントページを確認しました。これは、GitHub Copilot cloud agent のタスクを監視し、方向を調整するための場所です。アクティブなタスクと完了したタスクを追跡し、実行中の作業をレビューし、進行中のタスクに追加の指示を送って範囲を調整できます。

このレッスンでは、次の内容を確認しました。

- cloud agent のタスクを監視するために、ミッションコントロールとエージェントページを確認しました。
- 進行中のセッションに追加の機能を依頼しました。

Copilot がアクセシビリティ機能を実装している間、次は Copilot が作成したプルリクエストを[反復的に改善します][next-lesson]。
